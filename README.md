# Kayesthetic PBSMS Starter

A responsive frontend starter based on the Kayesthetic design shown in the supplied screenshots.

## Pages
- index.html — landing/home page
- login.html — sign-in page
- signup.html — sign-up page

## Shared files
- styles.css — typography, colors, layout, responsive behavior
- script.js — mobile navigation, password visibility, prototype form handling

## Assets
- assets/hero-portrait.jpg
- assets/how-it-works.jpg

The local images were cropped from the screenshots you supplied so this project can run offline.

## Run in VS Code
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Select “Open with Live Server”.

The login and sign-up forms are visual prototypes only. They are not connected to a database yet.
